# TT-Cross


This repo includes example about cross approximation for 2D matrix and high-dim tensor.



## Overview


3 examples:


- demo_matrix_cross,py: a toy example for 2D matrix cross approximation

- demo_ttcross.py: a toy example for high-dim tensor cross approximation

- demo_ttcross.ipynb: a toy example for high-dim tensor cross approximation (Jupyter file)
