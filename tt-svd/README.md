# TT-SVD
This is a tutorial about tensor decomposition (TT-SVD).


### Overview
- **utils.py**: including the implementation of TT-SVD and standard SVD

- 3 examples:
    - **ex0_random_data.ipynb**: a toy example with random data. You can play with this to have a basic understanding.
    - **ex1_face_pre.ipynb**: comparing the face prediction success rate, given similar amounts of data obtained by TT-SVD and SVD. The used dataset is [The Extended Yale Face Database B](https://academictorrents.com/details/06e479f338b56fa5948c40287b66f68236a14612). Note: You don't need to download it by yourself. It is already in data folder.
    - **ex2_sdf.ipynb**: comparing the sdf reconstruction precision, given similar amounts of data obtained by TT-SVD and SVD.
